Paso 1 · Encuentra los ceros

Resuelve x² − 4x + 8 = 0

Organiza tu procedimiento

x = (−b ± √(b²−4ac)) / 2a
a = ____ · b = ____ · c = ____
Discriminante: b²−4ac = ____
Dos ceros: x = ____ y x = ____
1
Identifica a, b y c.
Cuida el signo de b.
2
Calcula el discriminante.
Si es negativo, usa √−1=i.
3
Escribe las dos soluciones.
El signo ± produce un par conjugado.
Para esta ecuación: a=1, b=−4 y c=8. Después calcula (−4)²−4(1)(8).
